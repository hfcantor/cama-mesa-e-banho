# @hfr/inspector

Runtime diagnostics: loads compositions in headless Chromium and checks errors, timing, fonts, layout, blank frames, determinism and A/V sync.

## Uso

```bash
hfr inspect meu-video --samples 8 --thumbnails /tmp/thumbs
```
Verifica erros de runtime e de rede, fontes ausentes, clipes fora do quadro, quadros em branco, determinismo e A/V sync.
