# @hfr/registry

Component/template registry: discovery, parameters, insertion into compositions, local and remote (HTTP) registries.

## Uso

```bash
hfr registry list
hfr registry add bar-chart --param values=10,20,30 --param labels=A,B,C
```
Itens embutidos em `items/` (gerados por `scripts/build-items.py` e `scripts/build-templates.py`).
