# @hfr/studio

Studio web UI (vanilla TypeScript + CodeMirror 6), bundled on demand with esbuild and served by @hfr/studio-server.

## Uso

Interface servida por `@hfr/studio-server` (`hfr studio`). Abas: Editor, Timeline, Media, Validate, Render, Registry.
