# @hfr/lint

Static validation of compositions and projects (HTML, CSS, JS, timing, assets, media, captions, manifest).

## Uso

```bash
hfr lint meu-video [--json] [--disable timing/track-overlap] [--no-probe]
hfr lint --rules
```
