# @hfr/studio-server

Studio backend: REST API for projects, files, timeline edits, media uploads, validation, render jobs (SSE progress), registry, TTS and sharing; serves previews and the Studio UI.

## Uso

```bash
hfr studio --workspace ./projetos --port 4400 [--host 0.0.0.0]   # fora do loopback exige token
```
