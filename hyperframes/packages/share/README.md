# @hfr/share

Share bundles: static watch page (Open Graph, captions track, embed code), poster, checksums and a zipped project archive.

## Uso

```bash
hfr share renders/final.mp4 -o share --captions legendas.srt --project . --public-url https://exemplo.com/videos/final/
```
